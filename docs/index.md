# Smart Recipes

Умный генератор рецептов: отмечаете продукты, которые залежались в холодильнике — получаете 3 блюда с шагами.

## Что умеет

- Подбирает рецепты по совпадению ингредиентов
- Показывает недостающие продукты
- Помечает блюда, которые можно приготовить **прямо сейчас** (флаг `ready`)

## Установка

```bash
pip install -r requirements.txt
